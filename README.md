# Desafio Técnico - Linx 🚀

Este repositório contém a resolução do desafio técnico para a Linx. O objetivo do projeto foi aplicar correções lógicas e implementar melhorias de interface utilizando JavaScript.

## 🛠️ O que foi desenvolvido
* **Correção de Bug (Cálculo):** Ajuste na leitura de strings e conversão numérica (`parseFloat` e `replace`) para garantir o cálculo correto de descontos.
* **Manipulação de DOM:** Criação de validações para captura de atributos de produtos (ex: seleção de cor obrigatória) impedindo o envio de formulários incompletos.
* **Interface:** Estruturação em HTML e CSS para simular o ambiente de e-commerce e testar o funcionamento do script em tempo real.

## 💻 Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript (jQuery)
